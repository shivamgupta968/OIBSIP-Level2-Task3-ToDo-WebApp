# TaskFlow — OIBSIP Level 2 Task 3

A responsive To-Do Web App built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Add tasks with High, Medium or Low priority
- Separate Pending and Completed task lists
- Mark tasks complete and move them back to pending
- Edit task text and delete tasks with confirmation
- Live task counts and daily completion progress
- Added timestamp for each task
- LocalStorage persistence across refreshes
- Empty-state messages, input validation and responsive layout
- Accessible labels, buttons and status messages

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
This is a front-end demonstration. Tasks are stored in the current browser using LocalStorage; they are not synced to a server or other devices.
